# NGA-dense — compact counterfactual case study

`nga_dense` is a **synthetic-but-grounded** case study built to sit next to the **Mafa**
survey as a controlled comparison. It is generated by
[`scripts/build_nga_dense_example.py`](../../scripts/build_nga_dense_example.py) from the
**real georeferenced NGA 1 settlement** (`examples/nga_1/`).

## Why it exists

Comparing Mafa directly with the raw `nga_1` example is confounded: the two differ in
*both* geometry **and** demand scale (nga_1 is only ~16.6 kW vs Mafa's ~242 kW), so any
architecture difference could be attributed to scale alone. `nga_dense` removes that
confounder by **holding scale comparable to Mafa** and varying only settlement structure.

|                     | Mafa (real, dispersed)            | NGA-dense (this dataset)                |
|---------------------|-----------------------------------|-----------------------------------------|
| Connections         | 240                               | **240** (matched)                       |
| Aggregate peak      | 242 kW                            | **231 kW** (matched, within 5 %)        |
| Geometry            | polycentric; spread p90 ≈ 570 m, max 851 m | monocentric; spread p90 ≈ 202 m, max 255 m |
| Density (hull)      | 284 cust/km²                      | **2,250 cust/km²**                       |
| Demand distribution | heavy-tailed / institution-dominated (2×53 kW hospitals, one remote = 44 % of load) | homogeneous / residential (largest load 8 kW) |

Everything else — LV/MV conductor catalogues, transformer catalogue, stand-alone (SHS)
package catalogue and cost parameters — is **copied verbatim from Mafa** so the two runs
are directly comparable.

## How it is built

1. **Keep** all 128 real NGA 1 household coordinates (the real-case anchor).
2. **Densify** to 240 connections by infilling ~112 dwellings sampled near existing points
   (σ ≈ 12 m, clipped to the settlement's convex hull) — denser, same compact footprint.
3. **Diversify types**: the 14 points closest to the centroid become a compact central
   market / institution core (1 health clinic, 2 schools, 2 mosques, 1 admin office,
   5 shops, 3 productive units); community/institutional loads are `must_connect`.
4. **Diversify demand**: households draw an MTF tier mix (t2/t3/t4 ≈ 15/40/45 %) mapped
   through Mafa's `TIER_DEMAND`, so aggregate demand lands ≈ Mafa's without any large anchor.

Regenerate with:

```
python scripts/build_nga_dense_example.py
```

The generator is seeded (`SEED = 20260701`) and reproducible.
